## Limitations

1. The artifacts are unsigned. The Chryypt certificate is self-signed and untrusted, so
   SmartScreen will warn and no warning-free install is claimed.
2. The NSIS run was a fresh install, not a 0.1.0 → 0.2.0 upgrade. Same-version repair was
   not repeated in this pass.
3. The run used the real profile, not a clean Windows VM or a second Windows version.
4. The MSI was not installed or uninstalled with elevation.
5. The full desktop journey suite was last run against the 0.1.0 working tree in the Phase 8
   audit; it was not rerun against this release build.
